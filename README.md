# 🛒 Kovai Fresh Mart — Local Store E-commerce Platform

A fully functional e-commerce website built for a local store, developed as **Task 3** of the **Prodigy Infotech Web Development Internship**.

## 📋 Task Description
Create an e-commerce website for a local store, enabling customers to browse and purchase products online. The platform features product listings with images, descriptions, prices, and shopping cart functionality.

## ✨ Features

### Core Features
- 🛍️ Product listings with images (emoji-based), descriptions, and prices
- 🛒 Fully functional shopping cart (add, remove, update quantity)
- 💳 Checkout flow with customer details and payment method selection
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🌓 Light/Dark theme support

### Optional Features Implemented
- 📦 **Order Tracking** — real-time order status timeline (Placed → Packed → Out for Delivery → Delivered)
- ⭐ **User Reviews** — customers can view and submit product ratings & reviews
- 💬 **Customer Support** — FAQ section + support message form
- 🔍 **Sort & Filters** — search by name, filter by category, price range slider, sort by price/rating/name

## 🛠️ Built With
- HTML5
- CSS3 (custom properties, responsive grid/flexbox, dark mode)
- Vanilla JavaScript (no frameworks/libraries)
- Browser localStorage for cart, orders, and reviews persistence

## 🚀 How to Run
1. Clone this repository
2. Open `kovai-fresh-mart.html` in any modern web browser
3. No build steps or dependencies required — it's a single self-contained file
